# 02 — Company Data Collect

**Вход:** `{company_name, site, hh_url}` из модуля 01.
**Выход:** структурированные факты о компании, каждый — с URL источника.

## Что делать

1. Вызови все источники с `category: company_profile` из
   `config/sources.md` (сейчас это hh.ru и сайт компании):

   ```
   python scripts/hh_client.py --url <hh_url> --with-vacancies
   python scripts/site_crawler.py --url <site> --sections about,contacts
   ```

2. Собери из ответов: сферу деятельности, отрасль, регион, вакансии,
   значимые факты (штат, возраст компании, аккредитации, статусы).

3. **Каждый факт сохраняется вместе с URL источника — без этого он не
   попадёт в отчёт.** Это не стилистическое требование: отчёт без ссылок
   бесполезен для проверки перед outreach (п.3.3 ТЗ). Если скрипт вернул
   поле в `warnings` как ненайденное — это поле в отчёт не идёт (не
   заполняется приблизительно, не берётся из общих знаний о похожих
   компаниях).

4. Если `hh_client.py` вернул `ok: false` или пустые поля — это не повод
   останавливать модуль. Зафиксируй, что источник недоступен, и продолжи с
   тем, что дал `site_crawler.py` (и наоборот). Полный отказ модуля
   оправдан только если оба источника недоступны одновременно.

## Что писать в промежуточное состояние

Список фактов вида `{text, url, source}` — это то, что модуль 05 позже
разложит по блоку 1 отчёта строго по `config/report-structure.md`.

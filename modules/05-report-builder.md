# 05 — Report Builder

**Вход:** промежуточное состояние модулей 01–04 (данные о компании,
персоны с confidence, цифровой след).
**Выход:** markdown-отчёт по `templates/report-template.md`.

## Что делать

1. Собери отчёт **строго по `config/report-structure.md`** — шесть блоков в
   заданном порядке и составе. Это файл, а не память: перечитай его перед
   сборкой, а не полагайся на то, что запомнил структуру из предыдущей
   компании в batch-прогоне — структура блоков могла быть отредактирована
   пользователем между прогонами.

2. **Блок 3 — раздели `persons[]` из вывода `entity_resolve.py` (модуль
   03) на две группы перед записью, а не выводи одним списком:**
   - `hr_contact` — человек с позицией, похожей на HR-роль (HRD, директор
     по персоналу, HRBP, Head of Recruitment, HR-тимлид/Team Lead,
     рекрутер и т.п.) и `confidence_suggested` FIRM/CONFIRMED. Если таких
     несколько — старший по роли (HRD/директор по персоналу приоритетнее
     HRBP/линейного специалиста).
   - `other_lpr` — все остальные люди с FIRM/CONFIRMED (любая роль:
     CEO, CTO, CMO, основатель и т.п.).
   - **Отсутствие `hr_contact` не повод не заполнять `other_lpr`** — это
     ровно то, ради чего модуль 03 теперь ищет широко, а не только по
     HR-титулам (см. `modules/03-lpr-search.md`). Реальный пример:
     Вебпрактик — HR не найден, но CEO и CTO с рабочими Telegram-каналами
     нашлись и попали в отчёт как `other_lpr`.

3. Проставь confidence-метки по `config/confidence-levels.md` — бери
   значение `confidence_suggested` из вывода `entity_resolve.py` как есть,
   не переоценивай.

4. Пометь `partial`-источники (см. `config/sources.md`) там, где они
   использованы — фраза вида «источник с ограниченным охватом: публичная
   лента Telegram» рядом с соответствующими фактами.

5. Пометь автоматически определённые значения (из `resolved_automatically`
   модуля 01) как «определено автоматически, требует проверки».

6. Заполни `templates/report-template.md`, сохрани как markdown-файл в
   `paths.output` (из конфига) с именем на основе названия компании.

7. Если пользователь запросил PDF — вызови существующий pdf-скилл поверх
   готового markdown-файла (не переписывай логику генерации PDF здесь).

## Важно

Блок с фактом без ссылки на источник — ошибка сборки отчёта, а не
допустимое упрощение. Если факт есть, но ссылки на источник нет (например,
скрипт вернул значение без `url`) — такой факт в отчёт не включается.

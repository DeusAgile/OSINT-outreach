# Структура отчёта

Шесть блоков строго по разделу 4 ТЗ. Модуль `05-report-builder` читает этот
файл как источник истины по составу и порядку блоков — редактируется в
чате без правки самого модуля.

1. **Сфера деятельности** — чем занимается компания, отрасль, регион,
   значимые факты (штат, возраст компании, аккредитации, статусы). Каждый
   факт — со ссылкой на источник.

2. **Ключевые инсайты за период** (по умолчанию `report.insights_period_months`
   из конфига, 12 месяцев) — 3–7 тезисов, каждый со ссылкой. Если инсайтов
   меньше трёх — пишется как есть, не добирается домыслом.

3. **ФИО и контактные данные ЛПР/ЛВР** — целевые роли: HRD, директор по
   персоналу, HRBP, Head of Recruitment, линейные HR-специалисты. Если не
   найдено — прямо пишется «не найдено в открытых источниках», а не
   оставляется пустым и не выдумывается.

4. **Публичные страницы контактных лиц** — профили, ссылки на соцсети и
   профессиональные площадки для каждой найденной персоны.

5. **Описание интересов (цифровой след)** — публикации, выступления,
   комментарии, темы, которые персона поднимает публично. Основа для
   персонализации в блоке 6.

6. **Персонализированные материалы** — черновики outreach (Telegram, email).
   Опираются **только** на факты из блоков 1–5 — ни одного нового
   утверждения (anti-pattern.md).

## Общие правила оформления

- Каждый фактологический тезис — с URL источника (п.3.3 ТЗ), независимо от
  confidence-уровня.
- Автоматически определённые значения (сайт, hh.ru через `01-company-resolve`)
  помечаются пометкой «определено автоматически, требует проверки».
- Confidence-метка (`config/confidence-levels.md`) — рядом с каждым фактом
  о персоне, не заменяет ссылку на источник, а дополняет её.
- `partial`-источники (см. `config/sources.md`) помечаются в блоке, где
  использованы, как источник с ограниченным охватом.
